# Renan Andrade — Flutter & Mobile Accessibility

Personal portfolio for a Flutter engineer specializing in accessible mobile experiences, Firebase, APIs, and cross-platform product delivery.

The website uses semantic HTML and CSS, visible focus, reduced-motion support, responsive layouts, and no tracking.

## Local preview

Open index.html in a browser or serve the repository with any static file server.

## Deployment

The production copy is published with GitHub Pages from the main branch.
